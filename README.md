# 📘 Book Rent CLI

**Book Rent CLI** is a terminal-based client application built in **Go (Golang)** that provides a convenient way to interact with the [Library Book Rent API](https://github.com/yourusername/library-book-rent-api)). Designed for both users this tool offers a clean, text-based interface to manage book rentals directly from the command line.

---

## 🚀 Features

- 🔎 Browse and search books
- 📥 Rent and return books
- 👤 User registration and login
- 📜 View current rentals and history
- 💳 Initiate payments and view status

---

## 🛠️ Built With

- **Go (Golang)**  
- **REST API** integration with Book Rent API  
- **JWT** for session management
